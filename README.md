# TFlow Project Page

Static project page for **Good Agentic Friends Do Not Just Give Verbal Advice: They Can Update Your Weights**.

## Local Preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` from this directory.

## Files

- `index.html`: project page content.
- `static/css/index.css`: page styling adapted from the LLaVA-PruMerge/Nerfies-style template.
- `static/images/`: figures extracted from the paper LaTeX package.
- `static/paper/TFlow.pdf`: local copy of the paper PDF.
